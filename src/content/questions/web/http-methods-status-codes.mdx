---
title: "Các HTTP method phổ biến và nhóm status code cần nhớ?"
topic: web
roles: [frontend, fullstack, backend]
level: junior
tags: [http, methods, status-code, rest]
answer: "GET đọc, POST tạo/xử lý, PUT thay thế toàn bộ, PATCH sửa một phần, DELETE xóa. GET/PUT/DELETE là idempotent, GET còn là safe. Status: 2xx thành công, 3xx chuyển hướng, 4xx lỗi phía client, 5xx lỗi phía server."
---
| Method | Mục đích | Safe | Idempotent |
|---|---|---|---|
| GET | Đọc | Có | Có |
| POST | Tạo / hành động | Không | Không |
| PUT | Thay thế toàn bộ | Không | Có |
| PATCH | Cập nhật một phần | Không | Không đảm bảo |
| DELETE | Xóa | Không | Có |

```http
POST /api/orders HTTP/1.1
Content-Type: application/json

HTTP/1.1 201 Created
Location: /api/orders/42
```

| Code | Ý nghĩa |
|---|---|
| 200 / 201 / 204 | OK / Created / No Content |
| 301 / 302 / 304 | Redirect vĩnh viễn / tạm thời / Not Modified |
| 400 / 401 / 403 / 404 / 409 / 429 | Bad request / chưa xác thực / không đủ quyền / không tìm thấy / xung đột / quá rate limit |
| 500 / 502 / 503 / 504 | Lỗi server / bad gateway / quá tải / gateway timeout |

<Callout type="pitfall">
401 là chưa xác thực (chưa đăng nhập), 403 là đã xác thực nhưng không có quyền. Đừng dùng 200 kèm body báo lỗi.
</Callout>

<Callout type="followup">
Idempotent nghĩa là gọi N lần cho kết quả trạng thái giống gọi 1 lần, quan trọng khi retry; POST thường cần idempotency key.
</Callout>
