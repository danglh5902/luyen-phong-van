setTimeout(() => console.log('timer sau', Date.now() - t, 'ms'), 10);
// CPU nặng chặn event loop -> timer bị trễ

<Callout type="tip">
CPU nặng: dùng `worker_threads`, `child_process` hoặc tách ra service riêng. Ưu tiên API async (`fs.promises`) thay vì `readFileSync` trong request handler.
</Callout>
