## Nhà tuyển dụng muốn biết gì

- Bạn có tự ái khi bị góp ý không.
- Bạn có học từ góp ý không.
- Bạn có biết trao đổi lịch sự khi không đồng ý không.

## Cách trả lời

1. Nói bạn xem code review là cách học và giữ chất lượng chung.
2. Cách làm: đọc kỹ, hỏi lại nếu chưa rõ, sửa và cảm ơn.
3. Nếu không đồng ý: giải thích lý do bằng lời nhẹ nhàng, hoặc trao đổi trực tiếp.
4. Kể một ví dụ góp ý giúp bạn tiến bộ.

## Câu trả lời mẫu (English)

> I think code review is a good way to learn. When I get comments, I read them carefully. If I do not understand, I ask a question. Then I fix the code and say thank you.
>
> For example, a senior developer once told me that my function was too long and hard to test. I split it into small functions. Now I write cleaner code from the start.
>
> If I disagree, I explain my reason politely, and we find a good answer together.

<Callout type="pitfall">
Đừng nói tôi không bao giờ bị góp ý nhiều, hoặc tỏ ra khó chịu khi nói về chuyện này. Ai cũng nhận góp ý, kể cả senior.
</Callout>
