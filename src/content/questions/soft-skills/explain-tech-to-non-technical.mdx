## Nhà tuyển dụng muốn biết gì

- Bạn có giao tiếp rõ ràng với người ngoài đội dev không.
- Bạn có hiểu điều họ quan tâm không.
- Bạn có kiên nhẫn và không làm họ thấy mình ngốc không.

## Cách trả lời

1. Nói kết luận trước: chuyện gì xảy ra, cần quyết định gì.
2. Dùng ngôn ngữ đời thường và ví dụ so sánh.
3. Nói tác động: thời gian, chi phí, rủi ro cho người dùng.
4. Hỏi lại để chắc họ hiểu, có thể vẽ sơ đồ đơn giản.

## Câu trả lời mẫu (English)

> I start with the main point. For example, with a PM, I said: this feature needs two more weeks, because we must change the database first. I used a simple example: it is like fixing the road before we build a new shop.
>
> I do not use words like API or cache if they do not know them. I talk about time, cost, and users. At the end, I ask: is this clear? Do you have any questions? This way, we make decisions faster.

## Từ vựng hay dùng

| English | Nghĩa tiếng Việt |
| --- | --- |
| main point | ý chính |
| simple example | ví dụ đơn giản |
| it is like | nó giống như |
| time, cost, and users | thời gian, chi phí và người dùng |
| Is this clear? | Như vậy đã rõ chưa? |

<Callout type="pitfall">
Đừng dùng nhiều thuật ngữ rồi coi như họ phải hiểu, và đừng nói quá đơn giản đến mức sai sự thật chỉ để họ gật đầu.
</Callout>
