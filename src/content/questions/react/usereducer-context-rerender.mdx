---
title: "useReducer và Context: vấn đề re-render và cách khắc phục?"
topic: react
roles: [frontend, fullstack]
level: mid
tags: [context, useReducer, performance]
answer: "Khi value của Context đổi (so sánh Object.is), mọi component dùng context đó đều re-render, kể cả khi chỉ cần một phần dữ liệu. Giảm bằng cách tách context (state/dispatch), memo hóa value, hoặc dùng store có selector."
---
```jsx
const StateCtx = createContext(null);
const DispatchCtx = createContext(null);

function Provider({ children }) {
  const [state, dispatch] = useReducer(reducer, initial);
  return (
    <DispatchCtx.Provider value={dispatch}>
      <StateCtx.Provider value={state}>{children}</StateCtx.Provider>
    </DispatchCtx.Provider>
  );
}
```

- `dispatch` có identity ổn định, nên component chỉ gửi action (nút bấm) không re-render khi state đổi.
- Truyền `value={{ a, b }}` tạo object mới mỗi lần Provider render: bọc `useMemo`.
- Tách theo miền (AuthContext, ThemeContext) thay vì một context khổng lồ.
- `memo` ở con không ngăn được re-render do context: consumer luôn render lại khi value đổi.

<Callout type="pitfall">
Context không có selector: `useContext(Ctx)` đăng ký toàn bộ value. Nếu state đổi thường xuyên (vị trí chuột, form lớn), dùng Zustand/Redux hoặc `useSyncExternalStore` thay vì Context.
</Callout>

<Callout type="tip">
`useReducer` hợp khi state có nhiều trường liên quan và logic chuyển trạng thái phức tạp; reducer là hàm thuần nên dễ test.
</Callout>
